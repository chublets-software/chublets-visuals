# chublets-visuals

Graphics, tables and an overview page for [chublets.software](https://chublets.software):
the data model of the chublets Wikibase, the four-step pipeline, the FAIR4RS chain and the
open-archaeo to Wikidata workflow. Everything is generated by plain Python from vendored
model data, so every number in a graphic can be traced to a source file. No external
command-line tools are needed.

Overview of all graphics and tables: <https://chublets-software.github.io/chublets-visuals/>

Sibling repository of [FDOx-squirrel/fdox-visuals](https://github.com/FDOx-squirrel/fdox-visuals):
same house pattern, own palette.

## How it works

```
data/raw/<repo>/          vendored model tables (SHA-256 manifest, commits in SNAPSHOT.md)
      │
      ▼  py/model_data.py  the one place that reads them
      │
      ▼  py/step_*.py      geometry and text; numbers only from the model
      │
      ▼  main.py           runs the steps in order
img/*.svg + img/*.png      flat, transparent, 10 px border, licence in the metadata
captions.yaml              caption, alt text and sources for every graphic
tex/*.tex                  tables for a paper appendix (LaTeX longtable)
docs/                      overview pages for GitHub Pages
```

SVGs are rasterised in-process with [resvg-py](https://pypi.org/project/resvg-py/), using the
vendored Fira Sans, so a fresh clone renders identically on Windows, macOS and Linux.

## Usage

```cmd
pip install -r requirements.txt
python main.py
```

```cmd
python main.py --list                 show the steps
python main.py --only class-tree      rebuild one graphic
python main.py --from pattern         this step and everything after
python main.py --skip tables          everything but this
python main.py --dry-run              print the plan, run nothing
python main.py --strict               warnings become errors
```

Every step also runs on its own, for example `python py/step_class_tree.py`. A second run
changes nothing: `git status` stays clean.

## Tables

Eleven LaTeX tables in `tex/` (also as CSV and HTML on the overview page): the classes, the
properties by origin and topic, the CodeMeta terms, the evidence per property, the DataCite
evidence, the evidence sources and the model statistics. `tex/appendix-tables.tex` includes
all of them.

## Data sources

| Source | Vendored in |
|---|---|
| [chublets-wikibase-demo](https://github.com/n4o-rse/chublets-wikibase-demo) (model tables, review) | `data/raw/chublets-wikibase-demo/` |
| [wikibase-static](https://github.com/n4o-rse/wikibase-static) (kernel tables) | `data/raw/wikibase-static/` |
| [wikibase-federation](https://github.com/n4o-rse/wikibase-federation) (use case `chublets`) | `data/raw/wikibase-federation/` |
| [open-archaeo](https://github.com/n4o-rse/open-archaeo) (`py/wikidata/main.py`) | `data/raw/open-archaeo/` |

`data/raw/vendor-manifest.csv` lists a SHA-256 per file and `data/raw/SNAPSHOT.md` the commits.
To update, run `python py/vendor_sources.py` instead of copying by hand.

## Design

Colour and type live in `py/visuals_utils.py`: `CHUBLETS_PURPLE` (`#3B1F4A`) and
`CHUBLETS_GOLD` (`#B8862E`) are sampled from the logo, six category colours cover grouped
diagrams. Layout follows the measured text, never a fixed size, and coordinates are rounded
so that the SVGs are byte-identical from run to run. Typeface: [Fira Sans](https://github.com/mozilla/Fira),
vendored under `fonts/`. PNGs are cropped to their content plus a 10 px transparent border and
stay well below Google Slides' 25-megapixel limit.
